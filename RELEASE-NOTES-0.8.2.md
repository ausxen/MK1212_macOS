# MK1212 Mac Launcher 0.8.2

## 0.8.2

- Shows the MK1212 artwork briefly before opening the launcher.
- Adds a Credits window next to Help.
- Recovers automatically when launcher records point to a missing cache. The
  launcher rebuilds it, and the uninstaller continues once it verifies that
  no compatibility files are active.

## Compatibility fixes from 0.8.1

- Disables MK1212's Windows-only change-capital helper on macOS.
- Skips Windows-only custom-battle preference cleanup when APPDATA is unset.
- Uses Feral's macOS save folder for MK1212 Ironman save renaming.

The launcher supports Apple Silicon Feral ATTILA 1.6.1 build 480285.103778. The
current Steam and MK1212 Workshop installation was tested with the 13 core packs.
