Install ausxen's MK1212 macOS Launcher

This installer places the launcher and its uninstaller in:

/Applications/MK1212 Mac Launcher/

It does not include or modify Total War: ATTILA, Steam Workshop downloads, or saved campaigns.

Release 0.8.0 supports Feral ATTILA 1.6.1 build 480285.103778. If Steam or Feral changes the executable, the launcher stops safely and asks you to check for a newer release. This does not mean your game installation is damaged.
