ausxen's MK1212 macOS Launcher

DMG installation
----------------
Open `MK1212_macOS-0.7.0.dmg`, then drag the `MK1212 Mac Launcher` folder
onto the Applications shortcut. The installed folder is:

    /Applications/MK1212 Mac Launcher/

Open `MK1212 Mac Launcher.app` from that folder, or add that app to Steam as a
non-Steam game. To remove the launcher, close ATTILA and open
`Uninstall MK1212 Mac Launcher.app`.

Release 0.7.0 enables ten-slot settlements automatically on the supported
ARM64 Feral ATTILA 1.6.1 build. It patches only the running process; it does not
edit or re-sign the installed Feral application.

The launcher does not include Total War: ATTILA or Workshop content. Users must
own the game and subscribe to the required Workshop packs separately.
